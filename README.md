# Leitor de Extratos

Programa para Windows que le extratos bancarios em PDF e mostra os totais de credito e debito.
Tudo roda no seu computador: os PDFs nao sao enviados para nenhum servidor.

## Instalacao

Baixe o instalador `.exe` da versao mais recente em [Releases](../../releases/latest) e execute.
O programa avisa quando houver uma versao nova.
